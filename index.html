    USER MANUAL & OPERATIONAL GUIDE (ENGLISH)

    1. CDR Analyser

    Function Brief: Upload multi-operator CDR files to analyze target movements, call logs, and connected B-parties.
    Sub-sections:
    - Customized CDR: Filter call logs by date, type, direction, and find new numbers after a specific date.
    - Profile & Download: View target profile, edit details, upload target/NID images, view B-party profiles (with picture upload), location analysis, IMEI models, and download a full Word report.
    - Analysis Hub: Advanced analysis of Total/Night B-party, Locations, IMEI, and Common B-party/Location analysis across multiple targets.
    - Sorter Tools: Extract B-party numbers, format IMEIs, and sort BD numbers by operator.

    2. SMS Analyser

    Function Brief: Upload SMS dumps to view chronological message history. It automatically extracts utility links (WASA, DPDC, DESCO) and MFS numbers for quick copying.

    3. MFS Analyser

    Function Brief: Analyze bKash, Nagad, and Rocket statements. It classifies counterparties as Agent or Personal, shows total transaction summaries, and allows cross-account common number analysis.

    4. BTS Location Analyser

    Function Brief: Upload multiple BTS Excel files to store them locally in your browser. Search BTS locations using LAC/Cell ID, Lat/Lon, or full CDR text. It will automatically detect the operator and show the location on the map with Azimuth sectors.

    5. Tower Dump Analyser

    Function Brief: Load multiple Tower Dump files, map their columns (Date, Time, A-Party, B-Party, LAC, Cell, IMEI). You can group them by Location or Time (with auto-split features). It finds common A-parties, B-parties, or IMEIs across multiple locations/times. Clicking on a result number shows its exact Tower tracking details.

    ইউজার ম্যানুয়াল ও কার্যপদ্ধতি নির্দেশিকা (বাংলা)

    ১. সিডিআর এনালাইজার (CDR Analyser)

    সংক্ষিপ্ত বিবরণ: একাধিক অপারেটরের সিডিআর ফাইল আপলোড করে টার্গেটের মুভমেন্ট, কল লগ এবং যোগাযোগের বিশ্লেষণ করুন।
    সাব-সেকশনসমূহ:
    - কাস্টমাইজড সিডিআর: তারিখ, ধরন, দিক অনুযায়ী কল লগ ফিল্টার করুন এবং নির্দিষ্ট তারিখের পর নতুন নাম্বার খুঁজুন।
    - প্রোফাইল ও ডাউনলোড: টার্গেটের প্রোফাইল দেখা, তথ্য সম্পাদনা, ছবি/এনআইডি আপলোড, বিপার্টি প্রোফাইল (ছবিসহ), লোকেশন, আইএমইআই মডেল এবং সম্পূর্ণ ওয়ার্ড রিপোর্ট ডাউনলোড করুন।
    - অ্যানালাইসিস হাব: টোটাল/নাইট বিপার্টি, লোকেশন, আইএমইআই এবং একাধিক টার্গেটের মধ্যে কমন বিপার্টি/লোকেশন বিশ্লেষণ করুন।
    - সর্টার টুলস: বিপার্টি নাম্বার এক্সট্রাক্ট, আইএমইআই ফরম্যাট এবং অপারেটর অনুযায়ী নাম্বার সাজান।

    ২. এসএমএস এনালাইজার (SMS Analyser)

    সংক্ষিপ্ত বিবরণ: এসএমএস ডাম্প আপলোড করে কালানুক্রমিক মেসেজ হিস্ট্রি দেখুন। এটি স্বয়ংক্রিয়ভাবে ইউটিলিটি লিংক (ওয়াসা, ডিপিডিসি, ডেসকো) এবং এমএফএস নাম্বার কপি করার সুবিধা দেয়।

    ৩. এমএফএস এনালাইজার (MFS Analyser)

    সংক্ষিপ্ত বিবরণ: বিকাশ, নগদ এবং রকেটের স্টেটমেন্ট বিশ্লেষণ করুন। এটি অন্য পক্ষকে এজেন্ট বা পার্সোনাল হিসেবে চিহ্নিত করে, মোট লেনদেনের সারাংশ দেখায় এবং একাধিক অ্যাকাউন্টের মধ্যে কমন নাম্বার বিশ্লেষণ করতে দেয়।

    ৪. বিটিএস লোকেশন এনালাইজার (BTS Analyser)

    সংক্ষিপ্ত বিবরণ: একসাথে একাধিক এক্সেল ফাইল আপলোড করে ব্রাউজারের লোকাল স্টোরেজে (IndexedDB) বিটিএস ডাটা সেভ করুন। LAC/Cell ID, Lat/Lon অথবা সম্পূর্ণ CDR লগ পেস্ট করে বিটিএস এর লোকেশন সার্চ করা যাবে। এটি অটোমেটিক্যালি অপারেটর ডিটেক্ট করে ম্যাপে আজিমুথ সেক্টরসহ দেখাবে।

    ৫. টাওয়ার ডাম্প এনালাইজার (Tower Dump Analyser)

    সংক্ষিপ্ত বিবরণ: একাধিক টাওয়ার ডাম্প ফাইল লোড করে কলাম ম্যাপিং (তারিখ, সময়, এ-পার্টি, বি-পার্টি, LAC, Cell, IMEI) করুন। আপনি এগুলোকে লোকেশন বা টাইম অনুযায়ী গ্রুপ করতে পারবেন (অটো-স্প্লিট সুবিধাসহ)। এটি একাধিক লোকেশন/টাইমের মধ্যে কমন এ-পার্টি, বি-পার্টি বা আইএমইআই খুঁজে বের করে। রেজাল্টে নাম্বারে ক্লিক করলে সেই নাম্বারের টাওয়ার ট্র্যাকিং ডিটেইলস দেখা যায়।
