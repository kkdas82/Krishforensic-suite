USER MANUAL & OPERATIONAL GUIDE (ENGLISH)

1. CDR Analyser Module & Mobile Hubs

Function Brief: Features click-based mobile cards for Customized CDR, Profile & Analysis Hub, and Number Sorter/Extractors. Includes a **Cancel / Reset Current CDR** button to easily clear data and load a new CDR project.

2. Profile Word Report Download

Function Brief: In the Profile Hub, clicking Save & Download Profile Word generates a Word document containing exactly the filtered numbers, serial limits (Top 10, min usage), and records currently visible on screen.

১. মোবাইল ফ্রেন্ডলি কার্ড ও রিসেট অপশন

২. প্রোফাইল ওয়ার্ড ফাইল ডাউনলোড
